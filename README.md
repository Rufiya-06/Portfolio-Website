# Personal Portfolio Website

This is a simple static website developed using HTML, CSS, and JavaScript. The project demonstrates basic frontend web development concepts and is hosted using GitHub Pages.

## Features
- Responsive webpage layout
- Navigation menu
- Styled user interface using CSS
- Interactive button using JavaScript
- Simple and clean design

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Purpose
This project was created to practice frontend web development and GitHub hosting.

## Output
The website contains:
- Home section
- About section
- Contact section
- Interactive UI elements
